## 引擎复现

先用 Godot 导入导出包，再运行 `tests/verify_godot.gd`：

```bash
Godot --headless --path "<解压工程目录>" --import
Godot --headless --path "<解压工程目录>" \
  --script "<frame-studio绝对路径>/tests/verify_godot.gd" --fixed-fps 12
```

该脚本按 manifest 校验动作帧数、纹理资源、总帧数和过滤模式，并观察播放是否推进。若资产在另一工程的子目录，可在命令末尾加 `-- res://assets/`。向已有工程复制时应排除导出包的 `project.godot`，否则 Godot 会跳过这个嵌套工程目录。

像素资源搬迁后的实际输出：

```text
ANIMATION animation_前 frames=2 fps=12.0
ANIMATION float frames=4 fps=8.0
ANIMATION animation_后 frames=18 fps=12.0
GODOT_PLAYBACK_OK total=24 changes=22 filter=1
```
